01 — Featured Project

Movie & Theatre Ticket Booking System

A console-based Movie/Theatre Ticket Booking System developed using Java, JDBC, and MySQL. The system demonstrates database-driven operations through a Command Line Interface and follows DAO architecture to separate application logic from database operations.

01 — Overview

What I built.

The project automates a movie ticket booking workflow through a command-line application. It provides separate Admin and User flows while using MySQL for persistent application data.

01.5 — In Action

02 — The Problem

Why it exists.

Manual movie ticket booking and management can become time-consuming and error-prone. This project explores how a structured Java application and relational database can automate the management of movies, theatres, shows, users, and bookings.

03 — Features

What it can do.

Admin Module

Admin login and management operations.

Movie Management

Add and view movie records.

Theatre Management

Manage halls and screens.

Show Management

Create and view scheduled shows.

Ticket Booking

Database-driven ticket booking through the User module.

Revenue Dashboard

View revenue information from booking data.

04 — Architecture

How the system works.

The project follows a DAO (Data Access Object) architecture. Database operations are separated from the rest of the application, making the codebase easier to organize and maintain.

USER / ADMIN Application Interface
↓
JAVA Main Application
↓
DAO Data Access Layer
↓
JDBC Database Connectivity
↓
MYSQL Persistent Database
05 — Database

Data behind the system.

The application uses a MySQL database named movie_db. The repository documents tables for admins, movies, halls, screens, shows, users, and bookings.

06 — Engineering

What I learned.

Building this project gave me hands-on experience with Java JDBC, DAO architecture, MySQL schema design, database debugging, and building a CLI-based application around persistent data.

One of the key learning outcomes from this project was understanding how a Java application can interact with persistent relational data through JDBC while keeping database access organized through the DAO layer.
